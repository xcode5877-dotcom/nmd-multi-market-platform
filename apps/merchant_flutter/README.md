# Merchant Flutter (Sunmi V2)

Clean initialization for merchant app scaffolding.

## Structure

- `lib/core/api` - fixed API base URL (`https://nmd.marketing/api`)
- `lib/services/printer` - Sunmi printer integration logic
- `lib/models/order` - order pricing logic (net vs final)
- `lib/ui/theme` - minimal luxury, pill-shaped theme

## Notes

- No existing app folders were modified.
- This is a base scaffold; run `flutter pub get` inside this folder.
